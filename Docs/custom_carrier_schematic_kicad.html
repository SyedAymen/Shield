4-layer board setup in KiCad

1
Open Board Setup → Board Stackup. Click Add Layer twice to get 4 copper layers. Name them: F.Cu, In1.Cu, In2.Cu, B.Cu.
2
Set dielectric thickness to 0.2mm between L1–L2 and L3–L4 (signal pairs need thin dielectric for 100Ω target). Core between L2–L3 can be 1.0mm.
3
In Design Rules → Impedance, set differential impedance rule: 100 Ω, trace width 0.15mm, gap 0.15mm, layer F.Cu, ref layer In1.Cu (GND). Adjust W/S if your fab stackup differs.
4
Enable Interactive Router Settings → Use Net Tie Constraint. Set DRC rule for MIPI nets: length_matching 2mm.

Power plane on Layer 3 (In2.Cu) in KiCad

1
In PCB editor, select layer In2.Cu in the layer selector (bottom toolbar).
2
Use Place → Add Rule Area (or press Ctrl+Shift+Z). Draw a zone covering the +3V3 region (roughly the J1 side of the board). In the zone properties dialog: Net = +3V3, Fill = Solid, Layer = In2.Cu.
3
Repeat for +1V8: draw a second zone, Net = +1V8, on the J2 / U1 side. The two zones must have a 0.5mm clearance gap between them — KiCad enforces this automatically.
4
Press B to fill all zones. Use Inspect → Net Inspector to verify +3V3 and +1V8 are filled correctly on In2.Cu.

Never route MIPI pairs on In2.Cu or B.Cu. MIPI traces must be on L1 (F.Cu) with the solid GND plane on L2 directly underneath as the unbroken reference. Any gap in the L2 GND under MIPI traces destroys impedance control.

Labelling power pins in KiCad (PWR_FLAG)

1
In the schematic editor, press P to add a power symbol. Search for PWR_FLAG. Place one on every power net that connects to a connector pin but has no driver (e.g. +3V3, +1V8, VIN). This tells KiCad's ERC the net is intentionally sourced externally.
2
For named power rails, add a global label. Press P, search the net name (e.g. +3V3). Pins connected to this symbol are automatically shorted in the netlist — no wire needed across sheets.
3
Assign net names on the PCB side: open Edit → Net Classes. Create class POWER with min width 0.3mm, clearance 0.2mm. Assign +3V3, +1V8, VIN, GND to this class.
4
For connector pins, use the symbol's pin properties to set type to Power Input for GND/VCC pins and Power Output for regulated outputs (JMEDIA +3V3 OUT). This makes ERC errors meaningful.

Tip: add a PWR_FLAG at J1 pin 58 (+3V3), J2 pin 57 (+1V8), and J1 pin 57 (VIN). Without these, KiCad ERC flags "Pin unconnected" on all power nets even when they are connected to a connector.

Via rules — where vias are and are NOT allowed

Based on the schematic above:


  • NO vias on MIPI CSI-2 differential pairs (L0−/L0+, L1−/L1+, CLK−/CLK+). These run on L1 end-to-end from J1 to J3. A via introduces a stub and destroys impedance at multi-Gbps MIPI speeds.

  • NO vias on I2C signal traces (SCL0, SDA0, SCL2, SDA2). Keep these short and on L1.

  • Vias OK on +3V3 and +1V8 power nets — use 0.4mm drill / 0.8mm annular ring. The power planes on L3 can be accessed via stitching vias.

  • Vias OK on GPIO, MCLK, JMISC breakout signals — these are slow (LVTTL, I2C speed) and a via is fine.

  • GND stitching vias: place every 3–5mm alongside MIPI traces to reinforce the L2 GND reference. Use 0.3mm drill.
