FPC connector placement analysis
Where to put J3 (15-pin RPi camera FPC) relative to J1 (JMEDIA, 9.97 mm from left edge, body 38.1 mm)
Above J1 Not possible
Uno Q board occupies this space. Mating connector protrudes upward — no clearance for any component.
Right of J1 Difficult
Gap to JMISC is only ~18.7 mm. Differential pairs need 90° turn, risking impedance discontinuity. Tight space, awkward routing.
Left of J1 Requires board expansion
J1 is only 9.97 mm from edge. FPC body is ~15 mm wide — board must grow left ~5–8 mm. Differential pairs still need a 90° bend.
Below J1 (far edge) Recommended ✓
Traces run straight down from JMEDIA MIPI pins — no turns, no vias, no impedance breaks. FPC connector sits 15–20 mm below J1. Board height grows by ~20 mm (53→73 mm). Camera ribbon cable exits toward the far edge.
