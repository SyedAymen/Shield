⚠ VOLTAGE DOMAINS

All JMEDIA signals are 1.8V. RPi camera I²C (SDA/SCL) is 3.3V. The PCA9306 is mandatory — direct connection will damage the QRB2210 SoC. MIPI differential lanes are self-biased and connect directly.

⚠ MIPI LAYOUT RULES

Route Lane 0, Lane 1, and Clock pairs with 100Ω differential impedance. Match all pair lengths to ±2mm. No stubs, no vias, no width changes. Keep MIPI traces away from switching supplies.

ℹ POWER SOURCES

+3V3: JMEDIA pin 58 or 60 (OUT). +1V8: JMISC pin 57 (OUT). VIN (pins 57/59 on JMEDIA) is raw 7–24V — do NOT use for logic. Always add 100nF decoupling per IC supply pin.

ℹ PULL-UP RESISTORS

3.3V side (R1, R2): 10kΩ to +3V3. 1.8V side (R3, R4): 4.7kΩ to +1V8. Check if camera module already has 3.3V pull-ups — if so, R1/R2 are optional to avoid double-termination.

✓ CONNECTOR PART NUMBERS

J1/J2: Samtec FTSH-130-01-L-DV (male, 2×30, 1.27mm) — mates with Uno Q FLE-130. J3: Amphenol SFW15R-2STE1LF (15-pin FPC, 1mm). U1: TI PCA9306DCTR (SSOP-8).

✓ KICAD LIBRARY SOURCES

FTSH-130: Ultra Librarian (ultralibrarian.com). SFW15R: SnapEDA (snapeda.com). PCA9306: KiCad built-in — Interface_Voltage_Level_Translator:PCA9306. Resistors/caps: KiCad Device library.
